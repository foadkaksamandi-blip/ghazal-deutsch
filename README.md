# GHAZAL

اپ مستقل آموزش آلمانی برای غزل، با تمرکز بر مهاجرت و مدیریت زندگی واقعی در آلمان.

## ویژگی‌های نسخه اول

- اجرا روی Android و بهینه‌شده برای Samsung Galaxy S23 FE
- کاملاً آفلاین و بدون مجوز اینترنت
- ارزیابی اولیه سطح A1 تا C2
- خودارزیابی شش مهارت اصلی
- ۲۴ درس پایه در شش سطح
- ۱۲۰ واژه فعال همراه مثال و تلفظ گوشی
- مرور فاصله‌دار و بانک اشتباه‌ها
- تمرین شنیداری با موتور گفتار آلمانی گوشی
- بسته مهاجرت برای اداره، خانه، درمان، بانک، کار و دانشگاه
- برنامه کمینه، عادی و فشرده
- اعلان محلی روزانه بدون اینترنت
- ذخیره اطلاعات روی گوشی و فایل پشتیبان قابل بازیابی
- امضای ظریف FOAD

## حریم خصوصی

برنامه هیچ مجوز اینترنتی ندارد. اطلاعات آموزشی، سابقه تمرین، خطاها و تنظیمات در حافظه داخلی برنامه روی گوشی ذخیره می‌شوند. حذف برنامه، بدون داشتن فایل پشتیبان، اطلاعات را حذف می‌کند.

## ساخت خودکار در GitHub

با هر بار قرارگرفتن فایل‌ها روی شاخه `main`، بخش GitHub Actions آزمون‌ها را اجرا و فایل زیر را می‌سازد:

```text
GHAZAL.apk
```

## نصب روی گوشی

1. فایل APK ساخته‌شده را دانلود کنید.
2. فایل را در Samsung My Files باز کنید.
3. اگر Android درخواست کرد، اجازه نصب از همان منبع را یک‌بار فعال کنید.
4. برنامه را نصب و اعلان‌ها را مجاز کنید.

## وضعیت نسخه

این مخزن پایه اجرایی نسخه ۱ است. محتوای فعلی برای آزمایش کامل سازوکار برنامه تهیه شده و پیش از تحویل نهایی باید محتوای آموزشی هر سطح توسعه و بازبینی زبانی شود.
